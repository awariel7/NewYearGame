# Маленькая игра для моих друзей!

Игра про спасение Нового года для разработчиков БД!
Восстанавливаем ОС, исправляем индексы, дозаполняем базу, чтобы все получили подарки к новому году!

# Требования

1. Python 3 на компьютере, на котором будут играть ваши друзья (или вы сами!)
2. Браузер (тестировалось только на Google Chrome)
3. Клавиатура и мышь
3. Хорошее настроение

# Как запустить

1. Склонировать репозиторий с игрой на компьютер, где будет запущена игра
2. Запустить командную строку
3. В командной строке перейти в папку с файлами игры (для Windows выполнить команду ```cd <путь к папке с игрой>```)
4. Затем в командной строке выполнить команду `python app.py`. В командной строке отобразится статус запуска, в случае успеха будет доступно сообщение `Running on http://127.0.0.1:5000`. Окно командной строки не закрывать!
5. В браузере перейти по адресу http://127.0.0.1:5000
6. Наслаждаться игрой!
7. Чтобы остановить приложение достаточно закрыть окно командной строки, где была запущена игра

# Как сделана

Как веб-приложение, которая разворачивается локально.
Игра написана на Python с помощью фреймворка Flask. Веб-странички, конечно же, на html, стили на css

## Структура проекта

`app.py` - основной файл игры с отрисовкой раундов
`rounds` - папка с раундами игры (задания) 
`templates` - шаблоны веб-страниц для отображения
`static` - стили css для веб-страниц

### Ядро игры

Файл `app.py` с логикой последовательной отрисовки стартовой страницы, страниц с раундами и финальной страницы

### Файлы с заданиями

Хранятся в папке `rounds`. 
Каждый файл должен содержать:
- текст задания для отображения на странице (task_desc)
- текст сообщения об ошибке (error_message)
- текст для отображения при успешном решении задания (success_message)
- текст для кнопки (button_text)
- функция проверки ответа

### Веб-Страницы и стили

Шаблоны для страниц хранятся в папке templates:
`start` - стартовая страница с приветствием (с анимацией снежинок)
`task` - шаблон страницы для заданий
`success` - шаблон страницы после успешного решения задания
`happyend` - финальная страница с поздравлениями (с анимацией снежинок)

Стили для страниц хранятся в папке `static`.
